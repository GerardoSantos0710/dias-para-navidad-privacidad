# Política de privacidad — Días Para Navidad

Sitio público de la política de privacidad de la app móvil **Días Para Navidad**.

La política refleja el comportamiento verificado en la versión `1.0.1+1`: la app no recopila datos personales ni integra anuncios o analítica; solo procesa localmente la fecha, hora y zona horaria para la cuenta regresiva y las notificaciones.

## Publicación

El sitio se publica desde la rama `main` mediante GitHub Pages.

URL prevista: <https://gerardosantos0710.github.io/dias-para-navidad-privacidad/>
