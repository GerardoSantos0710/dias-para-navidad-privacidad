Política de privacidad

Información clara sobre los datos tratados por la app y sus servicios publicitarios.

Vigente desde el 17 de octubre de 2026

Privacidad en breve

  • La cuenta regresiva y las notificaciones funcionan localmente.
  • La app muestra anuncios mediante Google Mobile Ads (AdMob).
  • El servicio publicitario puede recopilar y compartir datos técnicos.
  • No creamos cuentas ni solicitamos datos personales directamente.

1. Alcance

Esta política se aplica a la aplicación móvil Días Para Navidad, identificada en Android como com.gsestudios.diasparanavidad. La aplicación muestra una cuenta regresiva hasta Navidad y puede programar una notificación local para el 25 de diciembre.

2. Datos que tratamos

Días Para Navidad no crea cuentas de usuario ni solicita directamente nombres, direcciones, números de teléfono, contactos, fotografías, información financiera, ubicación precisa ni credenciales.

La aplicación integra Google Mobile Ads (AdMob). Este servicio puede recopilar y compartir automáticamente la dirección IP, que puede usarse para estimar la ubicación aproximada; interacciones con la app, como aperturas, toques y visualizaciones de anuncios; información de diagnóstico y rendimiento; y el identificador de publicidad de Android, el ID del conjunto de aplicaciones u otros identificadores del dispositivo.

3. Finalidades del tratamiento

Los datos técnicos indicados se utilizan para mostrar, personalizar y medir anuncios; elaborar estadísticas; mejorar el rendimiento; y detectar fraude, abuso o problemas de seguridad y cumplimiento.

La fecha, la hora y la zona horaria del dispositivo se procesan localmente para calcular cuánto falta para Navidad y programar la notificación. Esta información no se envía a nuestros servidores.

4. Servicios de terceros

Los datos publicitarios se transmiten a Google y pueden tratarse con sus socios publicitarios de acuerdo con sus propias políticas y controles. Puedes consultar las políticas de Google en policies.google.com/privacy y la información sobre publicidad en policies.google.com/technologies/ads.

No vendemos bases de datos ni compartimos información directamente con fines distintos de los descritos en esta política.

5. Permisos y notificaciones

En Android, la aplicación puede utilizar los siguientes permisos:

  • Internet: para cargar y mostrar anuncios.
  • Notificaciones: para mostrar el aviso de Navidad.
  • Alarmas exactas: para programar el aviso en la fecha prevista.
  • Inicio completado: para restaurar notificaciones después de reiniciar el dispositivo.
  • Identificador de publicidad: cuando esté habilitado por Android y la configuración publicitaria.

Puedes rechazar o desactivar las notificaciones desde los ajustes del sistema. La cuenta regresiva seguirá funcionando.

6. Seguridad, conservación y control

Los datos recopilados por Google Mobile Ads se cifran durante la transmisión mediante TLS. Google determina sus plazos de conservación conforme a sus políticas y obligaciones aplicables.

Puedes restablecer o eliminar el identificador de publicidad desde los ajustes de Android, administrar la personalización de anuncios en tu cuenta de Google, retirar permisos o desinstalar la aplicación. La app no mantiene una cuenta ni una base de datos propia que debamos eliminar.

7. Público y privacidad de menores

La aplicación está dirigida a usuarios de 13 años o más. No solicitamos deliberadamente información personal de menores ni ofrecemos cuentas, chat o formularios para enviar información personal.

8. Tus derechos

Según tu país, puedes tener derechos de acceso, corrección, oposición o eliminación sobre tus datos. Para datos tratados por Google, utiliza sus controles de privacidad y publicidad. Para consultas relacionadas con esta aplicación, puedes contactarnos mediante el correo indicado abajo.

9. Cambios a esta política

Si una versión futura cambia el tratamiento de datos, actualizaremos esta página y su fecha de vigencia antes de aplicar dichos cambios.
